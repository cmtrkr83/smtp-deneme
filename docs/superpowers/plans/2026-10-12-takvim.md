# Takvim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Genel Bakış'ta %50 takvim kutusu + herkese açık etkinlik CRUD'u canlıya almak.

**Architecture:** `events.json` dosyasına `atomicSaveJson` ile yazan 4 REST endpoint (var olan announcements kalıbı); ön yüzde ay ızgarası üreten saf-JS widget, veri önbellekli, admin modalı kutudan açılır. Yeni bağımlılık yok.

**Tech Stack:** Express.js, vanilla HTML+JS+CSS, node:test (yerleşik).

**Spec:** `docs/superpowers/specs/2026-10-12-takvim-design.md`

## Global Constraints

- JSON yazma her zaman `atomicSaveJson()` ile (ham `writeFileSync` yasak).
- Korumalı route'lar `Authorization: Bearer <token>` ister; yazma route'ları `requireAdmin(req, res)` kullanır.
- Arayüz metinleri Türkçe; tarihler ekranda `DD-MM-YYYY` (örn. 12-10-2026), saklamada `YYYY-MM-DD`.
- Yeni renkler sabit hex değil `var(--...)` ile; marka kırmızısı `#8b0000` aynen korunur.
- Testler: `npm test` (`node --test test/`) hepsi yeşil kalır.

## Review Focus

- `endDate < startDate` gelen POST/PUT → 400 ve dosya değişmez (Task 1 testi).
- Taze `DATA_DIR`'da `events.json` yokken GET → `[]`, sunucu çökmez (Task 1 testi).
- Başlık/açıklamadaki `<script>` ham saklanır ama takvim popup'ı `escHtml` ile çizer (Task 3 adımı).
- Bilinmeyen id'ye PUT/DELETE → 404, dosya değişmez (Task 1 testi).
- `startDate` `DD-MM-YYYY` gelirse → 400 (yalnızca `YYYY-MM-DD` kabul, Task 1 testi).
